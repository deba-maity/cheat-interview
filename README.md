# Keyboard Shortcuts

| Shortcut | Description |
| --- | --- |
| Ctrl+L | Show the app and start or stop listening. |
| Ctrl+I | Show the app, capture the selected screen, and answer the current prompt. |
| Ctrl+Enter | Move the overlay to the next corner of the current display. |
| Ctrl+D | Switch between light and dark themes. |
| Ctrl+Shift+H | Show or hide the overlay. Hiding stops audio capture. |
| Ctrl+Shift+Q | Quit the application. |
| Enter | Send the question when typing in the question box. |
| Shift+Enter | Insert a new line in the question box. |
| Escape | Cancel pending work while the app is focused and Settings is closed. |
